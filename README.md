# Study02_ToDoList

매일 10~20개의 할 일을 관리하는 개인용 할 일 관리 웹 앱입니다.
순수 HTML/CSS/JavaScript로 만들었고, 브라우저에서 바로 실행되며 새로고침해도 데이터가 유지됩니다.

## 현재 상태

구현 완료. [PRD](PRD.md)의 기능을 모두 구현했습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 서버나 설치가 필요 없습니다.

## 주요 기능

- 할 일 추가, 수정(더블클릭 또는 수정 버튼, Enter 저장 / Esc 취소), 삭제(확인 창)
- 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)와 필터 탭
- 진행률 보기 (전체 및 카테고리별)
- `localStorage`에 자동 저장되어 새로고침 후에도 유지

## 파일 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (모바일 폭 대응 포함) |
| `app.js` | 동작 로직, 진행률 계산, 저장 |

## 기술 스택

- HTML, CSS, JavaScript (프레임워크·빌드 도구 없음)
