# Study02_ToDoList

매일 10~20개의 할 일을 관리하는 개인용 할 일 관리 웹 앱 프로젝트입니다.
순수 HTML/CSS/JavaScript로 만들고, 브라우저에서 바로 실행되며 새로고침해도 데이터가 유지되는 것을 목표로 합니다.

## 현재 상태

기획 단계입니다. 구현 전에 요구사항을 정리한 [PRD](PRD.md)만 포함되어 있습니다.

## 주요 기능 (계획)

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)
- 진행률 보기 (전체 및 카테고리별)
- `localStorage` 기반 데이터 저장

## 기술 스택

- HTML, CSS, JavaScript (프레임워크·빌드 도구 없음)
